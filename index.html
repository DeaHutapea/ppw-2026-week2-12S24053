Portofolio Pribadi (Minggu 2)

Dibangun memakai HTML5 semantik penuh: header, nav, main, tiga section, aside, footer.

  • Tabel data dengan caption, thead, tbody, tfoot, dan atribut scope
  • Dua jenis list — ordered dan unordered
  • Formulir 9 jenis input dengan label accessible

Formulir Konsultasi Accessible

Formulir dikelompokkan dengan fieldset dan legend, setiap input berpasangan label for/id, dan validasi native lewat atribut required serta aria-describedby.

Navbar & Hero Responsif

Navbar Bootstrap dengan breakpoint lg (992px) — di bawah lebar itu menu otomatis berubah jadi tombol hamburger yang bisa dibuka-tutup tanpa error console.

Specificity & CSS Variables

Demo perhitungan skor spesifisitas (inline, id, class, element), pseudo-element ::before untuk mikro-interaksi, dan variabel CSS di :root untuk tema warna terpusat.

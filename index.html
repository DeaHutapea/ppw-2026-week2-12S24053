Tentang saya

Saya mahasiswa S1 Sistem Informasi Institut Teknologi Del. Saya suka mengubah rancangan antarmuka menjadi kode yang bersih: struktur yang masuk akal buat pembaca layar, warna yang kontrasnya cukup, dan tata letak yang tidak pecah di layar kecil.

Keahlian utama

  • HTML5 semantik
  • CSS modern (Flexbox & Grid)
  • Aksesibilitas WCAG 2.2 AA
  • Git & GitHub Pages

Cara saya mengerjakan proyek

  1. Menentukan tujuan halaman dan siapa penggunanya.
  2. Menyusun kerangka HTML semantik sebelum menyentuh CSS.
  3. Menata visual: tipografi, warna, jarak, lalu responsif.
  4. Menguji dengan keyboard dan DevTools, baru deploy.
